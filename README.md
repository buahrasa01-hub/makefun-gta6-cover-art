# Vice Sunset Cover Maker

Turn your own photo and a few words into an original, sunset-soaked multi-panel cover. The studio runs entirely in your browser: photos stay on your device and exports are full-resolution PNGs.

## Run it

Use Node 22, then open [http://localhost:8080](http://localhost:8080):

    node serve.ts

## Make it yours

- Start with the coastal boulevard or neon pier sample, or add local JPG and PNG photos.
- Choose hero, three-strip or four-panel grid composition. Select a panel, zoom and drag to reframe its photo.
- Write a headline, set its size, move it to the top or bottom and toggle the ink outline.
- Pick Vice Sunset, Neon Hour or Palm Dusk colour grading and export square, portrait or landscape PNG.
- Screenshot scenes are available with ?shot=cover and ?shot=editor; query options include photo, caption, size, layout and grade.

The display lettering uses Noto Sans Display Condensed ExtraBold, a Google Noto font distributed under the SIL Open Font License 1.1. Its font file and OFL text are included in app/fonts; the UI uses system sans-serif fonts. The artwork and design are original and use no game logos, wordmarks or artwork.
